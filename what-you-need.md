# What you need

Make sure you have all of these before you start.

| Item                   | Why you need it                                                                                                    |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------ |
| **Tundra Tracker**     | Required to attach to the main hardware tracker unit.                                                              |
| **USB-C data cable**   | Required for flashing the JSON configuration file onto your Tundra Tracker. Must be a data cable, not charge-only. |
| **SteamVR**            | The core virtual reality platform runtime.                                                                         |
| **Keyboard and mouse** | You'll need traditional peripherals to navigate Windows during setup.                                              |
