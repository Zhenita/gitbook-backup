# Step 3: Update firmware

{% stepper %}
{% step %}
## Unpack and run the flasher

Unpack and run `eoz glove toolbox.exe`.

If a Windows security prompt appears, select **Run anyway**.
{% endstep %}

{% step %}
## Select the Firmware tab

You should see the screen below.

Click **Update**.

![Update firmware button in the EOZ Glove Toolbox](<.gitbook/assets/flash firmware.png>)
{% endstep %}

{% step %}
## Connect the glove

Turn on your Tundra Tracker and wait for the green LEDs on the glove to turn on.

Connect the glove's USB-C port to your PC.
{% endstep %}

{% step %}
## Update both ports!! (Very Important)

The firmware update starts automatically.

When it's complete, repeat for the glove's other USB-C port.
{% endstep %}

{% step %}
## Repeat the same process for the other hand

Repeat for the other hand.
{% endstep %}
{% endstepper %}
